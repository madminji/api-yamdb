## Эндпоинты отзывов и комментариев

- `/api/v1/titles/{title_id}/reviews/` – список и создание отзывов.
- `/api/v1/titles/{title_id}/reviews/{review_id}/` – получение, обновление, удаление отзыва.
- `/api/v1/titles/{title_id}/reviews/{review_id}/comments/` – список и создание комментариев.
- `/api/v1/titles/{title_id}/reviews/{review_id}/comments/{comment_id}/` – получение, обновление, удаление комментария.
